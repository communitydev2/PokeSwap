The user works across two Claude accounts (and Codex), often with several chats at once. Every piece of work keeps
its own handover file here, so any new chat on any account can continue it. Rule:
`C:\Users\Migue\Desktop\Claude Rules\handover-for-account-switch`.

- One file per piece of work, named after it (`handovers/<topic>.md`). A chat writes only its own file.
- Each file ends with "Where we are - <date time>": done (commits), open right now + next step, waiting on the user,
  decisions made, where things live.
- Update it after every meaningful step and commit + push it with the work. Add/refresh its line below.

To continue: "Read handovers/README.md and continue <topic>" (or "continue whatever is waiting on me").
